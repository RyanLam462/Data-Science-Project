# Predicting Commercial Unit Survival in Edinburgh

This data science project investigates whether geographic location or commercial classification is a stronger predictor of long-term commercial unit survival in Edinburgh.

I used Python to clean and combine five City of Edinburgh Council datasets covering 1986 to 2015. After processing the data, I analysed 6,712 commercial units using visualisations, chi-squared tests and logistic regression.

## Key Finding

Geographic location was a substantially stronger predictor of long-term survival than commercial classification. The interaction between the two factors was not statistically significant.

## Technologies

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Scikit-learn
* Statsmodels
* SciPy

## How to Run the Project

1. Clone the repository:

```bash
git clone <repository-url>
cd <repository-name>
```

2. Install the required Python packages:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn statsmodels scipy jupyter
```

3. Ensure the project has the following structure:

```text
project-folder/
├── datasets/
│   ├── Shop_Survey_1986.csv
│   ├── Shop_Survey_1996.csv
│   ├── Shop_Survey_2004.csv
│   ├── Shop_Survey_2010.csv
│   └── Shop_Survey_2015.csv
├── edinburgh_map.png
└── project-notebook.ipynb
```

4. Start Jupyter Notebook:

```bash
jupyter notebook
```

5. Open the project notebook and select **Run All Cells** to reproduce the data cleaning, analysis, models and visualisations.
