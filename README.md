# Predicting Commercial Unit Survival in Edinburgh

This data science project investigates whether geographic location or commercial classification is a stronger predictor of long-term commercial unit survival in Edinburgh.

I used Python to clean and combine five City of Edinburgh Council datasets covering 1986 to 2015. After processing the data, I analysed 6,712 commercial units using visualisations, chi-squared tests and logistic regression.

## Key Finding

Geographic location was a substantially stronger predictor of long-term survival than commercial classification. The interaction between the two factors was not statistically significant.
